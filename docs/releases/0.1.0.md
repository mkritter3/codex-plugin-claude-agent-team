# 0.1.0 Release Notes

This private release establishes the provider-neutral Agent Team MCP runtime with Claude Code CLI subscription OAuth as the primary v1 transport.

## MCP Tool Surface

The release includes public MCP tools for role listing, doctor checks, dispatch, durable starts, bounded parallel starts, status, batch status, messaging, batch messaging, replies, summaries, team records, dashboard inspection, cancellation, wind-down, and cleanup.

The MCP schemas stay provider-neutral. They do not expose provider command details, prompts, provider session identifiers, or storage internals.

## Provider Compatibility

Claude Code CLI subscription OAuth is the primary supported v1 transport. OpenAI-compatible, Ollama Cloud, Grok, and Gemini adapters are explicit opt-in read-only provider paths with provider-scoped auth configuration and no implicit fallback.

Read-only provider profiles do not support background sessions, live stdin, resume, cancellation, edits, tools, or isolated worktrees in this release.

## Config Schema Version

Workspace config uses `schemaVersion` `1`. Existing configs without `schemaVersion` are treated as version `1`.

Unsupported future config schema versions fail closed during config loading and `agent_team_doctor`. Operators should upgrade this plugin before operating a workspace that declares a newer config schema.

## State Layout Version

Workspace state uses layout version `1`. The optional marker lives at `.agent-team/state-layout.json`.

`agent_team_doctor` treats a missing marker as compatible for existing workspaces, accepts `{"layoutVersion":1}`, fails closed on future integer versions, and reports malformed markers as corrupt state requiring operator review.

Doctor is read-only for state layout checks. It does not migrate, repair, archive, delete, or rewrite workspace state.

## Migration Notes

No migration is required for existing local workspaces that do not declare `schemaVersion` or `state-layout.json`.

Before using a packaged runtime, run:

```bash
npm run ci
npm run smoke:package
```

`npm run ci` includes typecheck, tests, build, packaged stdio smoke, and dry-run package smoke.
